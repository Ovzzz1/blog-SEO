TL;DR

  • L'offre Eskimoz "Consultant·e SEO & GEO" demande explicitement "Premières compétences en Python OU en automation (Make, n8n)" — Python est listé dans leur stack "IA & Automation" aux côtés de ChatGPT, Claude, Make, n8n et l'API Ahrefs. Ce n'est pas un poste de dev : on cherche un consultant qui sait lire un script, l'adapter, le lancer et automatiser un peu. Le R&D et la data lourde sont gérés par leur pôle Data Scientists / Data Engineers internes.
  • Le 80% de la valeur tient en ~7 cas d'usage : (1) manipuler des exports CSV/Excel volumineux avec pandas, (2) requêter l'API Google Search Console, (3) faire du redirect mapping avec polyfuzz/RapidFuzz, (4) analyser des log files, (5) clusteriser des keywords par embeddings, (6) scraper / crawler des pages, (7) automatiser des reportings.
  • Les 5 concepts à maîtriser absolument : variables/types, listes & dictionnaires, boucles for, lecture/écriture CSV-Excel via pandas, gestion d'API avec requests + JSON, et le réflexe Google Colab. Si tu maîtrises ces blocs + 2-3 scripts génériques, tu couvres déjà 80% des demandes opérationnelles.

03

Pourquoi Python en agence SEO

  • Les exports SEO crashent Excel : un crawl complet ou un export GSC dépasse la capacité d'Excel. Pandas avale 1M+ lignes sans broncher.
  • Les API gratuites sont sous-exploitées : GSC API, GA4 Data API, PageSpeed API, Indexing API. Trois lignes de Python remplacent une demi-journée de copier-coller.
  • L'effet de levier sur le portefeuille : un script de redirect mapping fait passer une migration de "10 heures de junior" à "5 minutes de script + 2 h de QA".
  • Le pivot GEO/IA : l'écosystème SEO mélange embeddings, appels LLM et monitoring de citations. Python est la lingua franca de cet écosystème.
04

Les use cases Python les plus rentables

Manipulation d'exports tabulaires (le pain quotidien)

  • Lire un crawl Screaming Frog avec pd.read_csv() ou pd.read_excel().
  • Filtrer les URLs en noindex, les title vides, les title >60 caractères, les pages orphelines, les redirections en chaîne.
  • Croiser plusieurs sources : GSC + GA4 + crawl + Ahrefs sur la clé "URL" via pd.merge().
  • Comparer deux crawls (text-only vs JavaScript rendered) pour détecter les pages où Googlebot ne voit pas le contenu.

Analyse GSC à grande échelle

  • L'UI GSC est plafonnée à 1 000 lignes par export. Avec l'API GSC + Python, on extrait 25 000 lignes par requête.
  • Use cases concrets : détection de cannibalisation de mots-clés, pages "striking distance" (positions 11-20), opportunités de CTR.

Redirect mapping pour migrations

  • Crawl du site legacy + crawl du site cible avec Screaming Frog.
  • Script Python qui matche les URLs anciennes/nouvelles via fuzzy matching sur le slug, le H1 et le title.
  • Librairies : polyfuzz ou RapidFuzz.

Analyse de log files (Googlebot)

  • Quelles sections du site Googlebot crawle réellement.
  • Pages crawlées mais non indexées (cassure de crawl budget).
  • Outil de référence : advertools.logs_to_df() qui parse un access log directement en DataFrame parquet.

Crawl & scraping ciblés

  • Crawl de masse : advertools.crawl() ou screamingfrogseospider en CLI.
  • Scraping ponctuel : requests + BeautifulSoup.

Clustering sémantique de keywords

  • Méthode : embeddings (OpenAI ou sentence-transformers) + clustering (hdbscan ou KMeans).
  • Use case : sortir d'un export Ahrefs de 50 000 keywords des clusters d'intention de recherche.

Reporting / dashboards automatisés

  • Pull GA4 : librairie google-analytics-data.
  • Pull GSC : google-searchconsole.
  • Push vers Google Sheets / Looker Studio / BigQuery : gspread, pandas-gbq.

Ce qu'un consultant doit comprendre

L'objectif n'est pas de devenir développeur. C'est de lire un script, le modifier, le faire tourner sans paniquer quand une erreur s'affiche, et savoir demander à ChatGPT/Claude de l'adapter.

  • Variables et types (str, int, float, bool).
  • Listes [ ] et dictionnaires { }.
  • Boucles for : for url in urls: parcourir une liste d'URLs.
  • Conditions if / elif / else : tester un status code, vérifier qu'un H1 existe.
  • Lecture/écriture de fichiers tabulaires : pd.read_csv('export.csv'), df.to_excel('output.xlsx').
  • Manipulations pandas de base : df.head(), df.shape, df[df['Status Code'] == 404].
  • Appel à une API REST : requests.get(url).
  • Environnements : utiliser Google Colab pour 80% des cas.
💡 Hack 2026

Avec Claude Code, Cursor ou ChatGPT, un consultant non-dev peut générer 80% du code dont il a besoin à condition de savoir formuler la demande avec les bonnes briques mentales.

Caveats

⚠ Attention

L'offre WTTJ Eskimoz n'a pas pu être fetchée directement (URL bloquée) ; les éléments cités viennent du cache Google. L'écosystème Python-for-SEO bouge vite : pyGTrends est obsolète, et l'API Universal Analytics est dépréciée au profit de GA4.

  • "Premières compétences en Python ou en automation" est une formulation soft. Concrètement, tu peux passer le process avec uniquement Make/n8n + de la curiosité Python.
  • Attention au scraping de Google directement : les ToS l'interdisent. Passer par une API tierce (SerpApi, ValueSERP, DataForSEO).
  • La distinction Python "vrai" vs Python "via LLM" n'a jamais été aussi floue qu'en 2026. Un consultant équipé de Claude/Cursor peut produire des scripts qu'il ne saurait pas écrire de tête.
